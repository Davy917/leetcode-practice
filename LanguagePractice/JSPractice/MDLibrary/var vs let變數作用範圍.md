`var` 和 `let` 的核心差異在於**作用域（scope）**：

| 特性 | `var` | `let` |
|------|-------|-------|
| 作用域 | **函式作用域**（function scope） | **區塊作用域**（block scope） |
| 重複宣告 | 允許 | 不允許 |
| 變數提升 | 會提升，初始化為 `undefined` | 會提升，但進入 **暫時死區**（TDZ） |

**對你這題的影響：**

在遞迴解法中，你會宣告一個結果陣列，例如：

```javascript
// 用 var — 如果在迴圈或 if 區塊內宣告，外層也能存取
var result = [];

// 用 let — 嚴格限制在宣告的區塊內
let result = [];
```

**實務建議：** 現代 JS 一律推薦用 `let`（或 `const`），避免用 `var`，因為 `var` 的函式作用域容易造成意外汙染。
