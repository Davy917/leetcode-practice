## 1. 三元運算子

**語法：** `條件 ? A : B`

```js
3 > 1 ? console.log("true") : console.log("false")
```

---

## 2. 空值合併運算子（`??`）

**功能：** 處理 `null` 或 `undefined` 值

**語法：**
```js
a ?? b
```

- 如果 `a` 是 `null` 或 `undefined` → 回傳 `b`
- 否則 → 回傳 `a`

### 例子
```js
undefined ?? 10   // 10
null ?? 10        // 10
0 ?? 10           // 0
"" ?? "default"   // ""
false ?? true     // false
```

### vs `||` 的差別
`||` 會把「falsy」都當成要用預設值（如 `0`, `""`, `false`）：

```js
0 || 10   // 10   (可能不是你想要的)
0 ?? 10   // 0
```

## 3. 相等運算子：`==` vs `===`

```js
console.log(111 == '111')   // true  (自動型別轉換)
console.log(111 === '111')  // false (嚴格比較型別)
```

**建議：** 使用 `===` 避免隱性型別轉換的問題

## 6. 變數作用域

### 全域變數 vs 區域變數
```js
// 1. 全域變數
var y = 1

function variable() {
    // 2. 區域變數
    var x = 1
}

// 3. 全域屬性（不透過 var 宣告）
y = 3
```

## 7. `var` vs `let`

### `var` 的行為
```js
console.log(z)  // undefined (變數已宣告，未賦值)
var z = 10
console.log(z)  // 10
```

**特性：** `var` 會被提升（hoisting）

### `let` 的行為
```js
// console.log(k)  // ❌ ReferenceError: Cannot access 'k' before initialization
let k = 10
console.log(k)  // 10
```

**特性：** `let` 不能在宣告前存取（暫時死區 TDZ）

### 差異總結
| 特性 | `var` | `let` |
|------|-------|-------|
| 作用域 | 函式作用域 | 區塊作用域 |
| 提升 | 是（値為 undefined） | 是（暫時死區） |
| 重新宣告 | 允許 | 不允許 |

## 8. `const` 常數

### 基本用法
```js
const dog = 'Peter'  // 宣告後不能修改值
// dog = 'John'  // ❌ 錯誤
```

### `const` 物件
```js
const person = {
    name: 'huang',
    age: 20
}
person['name'] = 'Jason'  // ✅ 可以修改物件的屬性
console.log(person)  // { name: 'Jason', age: 20 }
```

**注意：** `const` 保護的是參考，不是物件內容

## 9. 解構賦值

### 陣列解構
```js
let [g, h, j] = [1, 2, 3]
console.log(g)  // 1
```

### 物件解構
```js
let {a: val, b: val2} = {a: 111, b: 222}
console.log(val)   // 111
console.log(val2)  // 222
```

## 10. 樣板字面值（Template Literals）

使用反引號 `` ` `` 來組合字串，直接在字串內插入變數：

```js
let name = 'Tom'
let str = `hello ${name}`
console.log(str)  // "hello Tom"
```

**優點：** 無須繁瑣的 `+` 號連接

## 11. 擴展運算子（Spread Operator）

詳細說明見：[Spread operator.md](/LanguagePractice/Compare4Language/Spread%20operator.md)

### 陣列中的應用

#### 將陣列拆成個別元素
```js
let arr1 = [1, 2, 3, 4, 5]
console.log(Math.min(arr1))      // NaN (Math.min 不接受 Array)
console.log(Math.min(...arr1))   // 1 (拆出來才能得到最小值)
```

#### 合併陣列
```js
const fruits = ['apple', 'banana']
const veggies = ['tomato', 'potato']

const food = [...fruits, ...veggies]
console.log(food)
// ['apple', 'banana', 'tomato', 'potato']
```

#### 在中間插入元素
```js
const moreFood = ['bread', ...fruits, 'milk']
console.log(moreFood)
// ['bread', 'apple', 'banana', 'milk']
```
