### JavaScript 中的 == 與 === 的差別

在 JavaScript 中，`==` 和 `===` 都是用來比較兩個值是否相等，但它們的核心運作方式不同：

### 1. `==` (Loose Equality / 相等運算子)
被稱為**抽象相等性比較**。它的規則是：在比較之前，如果兩個值的型別（Type）不同，JavaScript 會嘗試**進行型別轉換** (Type Coercion)，將它們轉為相同的型別後，再進行值的比較。

*   **特性**：可能會導致一些出乎意料的結果，因為它會自動轉換型別。

**範例：**
```javascript
1 == "1"      // true，因為字串 "1" 被轉成了數字 1
null == undefined // true，這是 JS 的特殊規則
0 == false    // true，因為 false 被轉成了數字 0
```

---

### 2. `===` (Strict Equality / 嚴格相等運算子)
被稱為**嚴格相等性比較**。它的規則是：**不會進行型別轉換**。只有當兩個值的「型別」完全相同，且「值」也完全相同時，才會回傳 `true`。

*   **特性**：比較安全、可預測，不會發生意外的型別轉換。

**範例：**
```javascript
1 === "1"      // false，因為數字型別不等於字串型別
null === undefined // false，型別不同
0 === false    // false，型別不同
```

---

### 總結與建議

| 運算子 | 名稱 | 是否進行型別轉換 | 比較內容 |
| :--- | :--- | :--- | :--- |
| `==` | 相等運算子 | 是 | 值 (型別不同時會先轉換) |
| `===` | 嚴格相等運算子 | 否 | 型別與值皆需相同 |

**最佳實踐**：
在絕大多數的開發情境中，**建議優先使用 `===`**。這樣可以避免因為 JavaScript 自動型別轉換帶來的隱藏錯誤，讓程式碼的邏輯更加清晰與穩定。
