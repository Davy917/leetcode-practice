# 陣列 / 矩陣初始化（Python / Java / Go / JavaScript）

以下整理兩個常見情境：

1. 建立長度為 `n` 的一維陣列（全部填 `0`）
2. 建立 `n x n` 的二維矩陣（全部填 `0`）

---

## 1) 長度為 `n` 的一維陣列，全部填 `0`

### Python

**基礎寫法**
```python
n = 5
nums = []
for _ in range(n):
    nums.append(0)
```

**簡潔寫法**
```python
n = 5
nums = [0] * n
```

### Java

**基礎寫法**
```java
int n = 5;
int[] nums = new int[n];
for (int i = 0; i < n; i++) {
    nums[i] = 0;
}
```

**簡潔寫法**
```java
int n = 5;
int[] nums = new int[n]; // Java int 預設就是 0
```

### Go

**基礎寫法**
```go
n := 5
nums := make([]int, n)
for i := 0; i < n; i++ {
	nums[i] = 0
}
```

**簡潔寫法**
```go
n := 5
nums := make([]int, n) // int 預設值是 0
```

### JavaScript

**基礎寫法**
```js
const n = 5;
const nums = [];
for (let i = 0; i < n; i++) {
  nums.push(0);
}
```

**簡潔寫法**
```js
const n = 5;
const nums = Array(n).fill(0);
```

## 2) 建立 `n x n` 二維矩陣，全部填 `0`

### Python

**基礎寫法**
```python
n = 5
nums = []
for _ in range(n):
    row = []
    for _ in range(n):
        row.append(0)
    nums.append(row)
```

**簡潔寫法**
```python
n = 5
nums = [[0] * n for _ in range(n)]
```

> 注意：不要寫成 `[[0] * n] * n`，這會讓每一列指向同一個 list。

### Java

**基礎寫法**
```java
int n = 5;
int[][] nums = new int[n][n];
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        nums[i][j] = 0;
    }
}
```

**簡潔寫法**
```java
int n = 5;
int[][] nums = new int[n][n]; // int 預設值是 0
```

### Go

**基礎寫法**
```go
n := 5
nums := make([][]int, n)
for i := 0; i < n; i++ {
	nums[i] = make([]int, n)
	for j := 0; j < n; j++ {
		nums[i][j] = 0
	}
}
```

**簡潔寫法**
```go
n := 5
nums := make([][]int, n)
for i := 0; i < n; i++ {
	nums[i] = make([]int, n) // int 預設值是 0
}
```

### JavaScript

**基礎寫法**
```js
const n = 5;
const nums = [];
for (let i = 0; i < n; i++) {
  const row = [];
  for (let j = 0; j < n; j++) {
    row.push(0);
  }
  nums.push(row);
}
```

**簡潔寫法**
```js
const n = 5;
const nums = Array.from({ length: n }, () => Array(n).fill(0));
```

> 注意：不要寫成 `Array(n).fill(Array(n).fill(0))`，這會讓每一列指向同一個陣列。
