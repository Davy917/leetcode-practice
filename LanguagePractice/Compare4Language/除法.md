### Java, JavaScript, Python, Go 除法運算比較

在演算法與日常開發中，不同語言對於除法（尤其是負數除法）的處理方式各異。以下整理了 Java、JavaScript、Python、Go 四種語言常見的除法寫法與行為。

---

#### 1. 一般除法 (浮點數除法)
返回精確的浮點數結果。

*   **Java**: `(double) a / b` 或 `1.0 * a / b` (若 `a`, `b` 皆為整數，直接 `a / b` 會執行整數除法)。
*   **Python**: `a / b` (Python 3 中 `/` 永遠返回浮點數)。
*   **JavaScript**: `a / b` (所有數字皆為 64位元浮點數)。
*   **Go**: `float64(a) / float64(b)` (Go 強制類型檢查，整數相除仍為整數)。

#### 2. 地板除法 (Floor Division)
返回小於或等於商的最大整數（向負無窮方向取整）。在處理負數時與「向零截斷」不同。

*   **Java**: `Math.floorDiv(a, b)` (Java 8+)。
*   **Python**: `a // b`。
*   **JavaScript**: `Math.floor(a / b)`。
*   **Go**: Go 沒有內建的地板除法函數（`a / b` 是向零截斷），需手動實現或使用 `math.Floor(float64(a)/float64(b))`。

#### 3. 向零截斷除法 (Truncate/Integer Division)
直接捨去小數位，正數向下取整，負數向上取整（LeetCode 大多數整數除法題目要求的行為）。

*   **Java**: `a / b` (整數類型相除)。
*   **Python**: `int(a / b)`。
*   **JavaScript**: `Math.trunc(a / b)` 或 `(a / b) | 0` (位運算僅限 32 位整數)。
*   **Go**: `a / b` (整數類型相除)。

#### 4. 四捨五入除法 (Round Division)
將結果四捨五入到最近的整數。

*   **Java**: `Math.round((double) a / b)`。
*   **Python**: `round(a / b)` (注意：Python 的 `round` 在 `.5` 時會向最近的偶數取整，例如 `round(0.5)` 是 0, `round(1.5)` 是 2)。
*   **JavaScript**: `Math.round(a / b)`。
*   **Go**: `math.Round(float64(a) / float64(b))`。

---

### 負數除法行為對比 (重點)

假設運算為 `-7 / 3`：
- **精確值**: `-2.333...`
- **向零截斷 (Truncate)**: `-2` (捨去小數)
- **地板除法 (Floor)**: `-3` (向負無窮取整)

| 語言 | 語法 | `-7 / 3` 的結果 | 備註 |
| :--- | :--- | :--- | :--- |
| **Java** | `a / b` | `-2` | 預設為向零截斷 |
| **Java** | `Math.floorDiv(a, b)` | `-3` | 地板除法 |
| **Python** | `a // b` | `-3` | 預設為地板除法 |
| **Python** | `int(a / b)` | `-2` | 實現向零截斷 |
| **Go** | `a / b` | `-2` | 預設為向零截斷 |
| **JS** | `Math.trunc(a / b)` | `-2` | 向零截斷 |
| **JS** | `Math.floor(a / b)` | `-3` | 地板除法 |

---

### 總結代碼範例

#### Java
```java
int a = -7, b = 3;
System.out.println(a / b);              // -2 (向零截斷)
System.out.println(Math.floorDiv(a, b)); // -3 (地板除法)
System.out.println(Math.round((double)a / b)); // -2 (四捨五入)
```

#### Python
```python
a, b = -7, 3
print(a / b)    # -2.333... (一般除法)
print(a // b)   # -3 (地板除法)
print(int(a / b)) # -2 (向零截斷)
```

#### JavaScript
```javascript
let a = -7, b = 3;
console.log(a / b);          // -2.333...
console.log(Math.floor(a / b)); // -3
console.log(Math.trunc(a / b)); // -2
console.log((a / b) | 0);    // -2 (效率最高，但限 32bit 整數)
```

#### Go
```go
a, b := -7, 3
fmt.Println(a / b)           // -2 (向零截斷)
// Go 沒有內建地板除法，通常需轉浮點數處理
fmt.Println(int(math.Floor(float64(a) / float64(b)))) // -3
```
