好的！以下說明**二元樹（Binary Tree）**和**二叉搜索樹（Binary Search Tree, BST）**的差別：

---

## 二元樹（Binary Tree）

- **定義**：每個節點最多有 **兩個子節點**（左、右）
- **對節點值沒有任何大小要求**，可以隨意排列
- 是一種**通用的樹形結構**

```
        5
       / \
      3   8
     / \
    9   1     ← 左子節點 9 比父節點 3 大，右子節點 1 比父節點 3 小，完全沒關係
```

---

## 二叉搜索樹（BST）

- 是一種**特殊的二元樹**，除了每個節點最多兩個子節點外，還必須滿足：
    1. **左子樹**所有節點的值 **<** 當前節點的值
    2. **右子樹**所有節點的值 **>** 當前節點的值
    3. 左右子樹本身也必須是 BST（遞迴性質）

```
        5
       / \
      3   8     ← 左邊都 < 5，右邊都 > 5 ✅
     / \
    1   4       ← 左邊都 < 3，右邊都 > 3 ✅
```

---

## 核心差別總結

| | 二元樹 | 二叉搜索樹 |
|---|---|---|
| 子節點數量 | 最多 2 個 | 最多 2 個 |
| 節點值大小規則 | **無限制** | **左 < 根 < 右** |
| 查找效率 | O(n)（可能要遍歷全部） | O(log n)（平均） |
| 關係 | 廣義概念 | 二元樹的**特例** |
