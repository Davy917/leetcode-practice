## 什麼時候用多源 BFS？

> **核心特徵：有多個起點，要找「每個細胞到最近起點的距離」**

| 情境 | 說明 | 類似題目 |
|---|---|---|
| 多個起點，找最近距離 | 每個細胞離最近的門/出口多遠？ | 286. Walls and Gates |
| 擴散問題 | 多個腐爛橘子同時擴散，全部爛掉要多久？ | 994. Rotting Oranges |
| 多邊界同時搜尋 | 從太平洋和大西洋邊界同時往內走 | 417. Pacific Atlantic Water Flow |
| 找最近的目標 | 每個細胞離最近的 0 有多遠？ | 542. 01 Matrix |

## 什麼時候用單源 BFS？

> **核心特徵：只有一個起點，找從它出發的最短路徑**

| 情境 | 說明 | 類似題目 |
|---|---|---|
| 單點最短路徑 | 從起點到終點最少走幾步？ | 一般迷宮題 |
| 層序遍歷 | 從根節點開始逐層遍历 | 102. Binary Tree Level Order |
| 連通塊 | 從一個點開始能到達哪些地方？ | 200. Number of Islands |
| 狀態轉換 | 從起始單字變到目標單字 | 127. Word Ladder |

## 一句話判斷法

- 看到「**多個起點，找最近的**」→ 多源 BFS
- 看到「**一個起點，找路徑**」→ 單源 BFS

## 為什麼多源 BFS 更好？

以 286-walls-and-gates 為例：

- **多個單源 BFS**：從每個門各跑一次 → 大量重複造訪 → O(k × m × n) 甚至更差
- **多源 BFS**：所有門同時出發，每個細胞只造訪一次 → O(m × n)

本質上就是**把 k 次 BFS 合併成 1 次**，避免重複工作。
