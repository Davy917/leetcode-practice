## 問題一：如何讓映射結果分布均勻？

要讓分布更均勻，可以思考以下方向：

1. **模數與桶數量一致**：`key % len(self.buckets)` 才能充分利用所有桶。
2. **桶數量選質數**：例如 769、1009 等質數，能減少 `key` 的規律性帶來的聚集。因為質數與大多數 key 值不共享因子，取模後分布更分散。
3. **更好的雜湊函數**：對整數 key，可以加入位元混合（bit mixing），例如：
   ```python
   def _hash(self, key):
       key ^= key >> 16
       key *= 0x85ebca6b
       key &= 0xffffffff
       return key % len(self.buckets)
   ```
   這類做法能打散相近 key 的聚集現象。

## 問題二：發生衝突時線性查找，怎麼優化？

你目前的程式碼其實是用**鏈地址法（chaining）**——每個桶掛一個 list，而非線性探測（linear probing）。

不過針對你的問題，如果是**線性探測**的情境，常見的優化方式有：

| 方法 | 思路 | 解決的問題 |
|------|------|-----------|
| **二次探測（Quadratic Probing）** | 步長改為 1, 4, 9, 16…（平方數） | 減少「一次聚集（primary clustering）」 |
| **雙重雜湊（Double Hashing）** | 第二個雜湊函數決定步長：`h2(key)` | 幾乎消除聚集現象 |
| **動態擴容（Rehashing）** | 當負載因子（元素數/桶數）超過閾值（如 0.75），擴大桶數並重新哈希 | 從根本上降低衝突率 |
